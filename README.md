專為您與女朋友兩位打造的**台灣全省「真人導覽景點」互動地圖與即時同步系統**。
100% 完全免費、免綁信用卡、免 API 金鑰，風格溫馨舒適，支援兩台 iPhone 手機即時雙向同步、桌面一鍵啟動、5 公里導覽雷達、今日場次與休館智慧標籤、Google Maps 導航、LINE 原生分享與 iPhone 行事曆整合！

## 🌟 核心特色功能

1. **全台灣 22 縣市完整收錄**
   - 涵蓋北部、中部、南部、東部及離島各大博物館、文化資產、古蹟群、國家公園與生態步道。
   - 每一筆均完整標示：**「真人導覽內容概述」**、**「導覽場次與時長」**、**「收費明細（免費/含門票/自費金額）」**、**「官方導覽原網頁連結」**與**「休館日」**。

2. **全台任一地點搜尋 + 周邊 5 公里導覽雷達**
   - **🔍 地點搜尋**：輸入台灣任一地名、地址、車站或老街（如「宜蘭傳藝」、「台南孔廟」、「大溪老街」），地圖立即鎖定該處。
   - **📍 GPS 定位**：一鍵抓取目前所在位置。
   - **👆 地圖任意點擊**：點擊地圖任意處，立即以該點為中心繪製 5km 半徑圈，自動計算距離並列出周邊所有真人導覽！
   - 支援 3km / 5km / 10km 快速切換。

3. **🟢 今日有導覽 / ⚠️ 今日休館智慧標籤**
   - 系統依當天星期幾自動比對休館資訊：
     - 若遇休館日，醒目顯示 ⚠️「今日休館」，防止情侶出門撲空！
     - 若正常開放，顯示 🟢「今日有導覽」，並精確計算下一場次倒數分鐘數（例如：`⏳ 下一場 14:00 (還有 35 分鐘)`）。

4. **🗺️ Google Maps 路線導航一鍵開啟**
   - 每個景點卡片與彈窗均內建「🗺️ Google Maps 導航」按鈕，點擊直接喚起手機 Google Maps 啟動即時導航或查看街景。

5. **💛 右側縣市分類收藏抽屜 (可收合/展開)**
   - 點擊右上角「💛 收藏」按鈕，右側滑出抽屜式面板。
   - 收藏清單**依縣市自動分組**（例如：台北市 (3 處)、台南市 (5 處)），點擊景點地圖自動平移動畫飛往該點並展開詳情。

6. **👫 兩人房間代碼即時雙向同步 (Cloud Realtime Sync)**
   - 兩人在各自手機或電腦的「⚙️ 設定」中輸入同一組**「房間代碼」**（例如：`ourlove`）。
   - 任何一方收藏景點、新增自訂導覽、或修改時間，另一方的畫面在 **1 秒內自動同步更新**！

7. **📅 iPhone 行事曆整合 + 兩人共享行程表**
   - 點擊「📅 加行事曆」，自動下載 `.ics` 行事曆檔，iPhone 一鍵加入內建行事曆並設定**提前 30 分鐘提醒**。
   - 同時自動登記在頂部的「📅 行程」共享清單中，兩人都看得到彼此安排好的導覽活動。

8. **📲 LINE 原生分享**
   - 點擊「📲 LINE 分享」，在 iPhone 上自動喚起 iOS 原生分享選單，排版好溫馨邀請文字、景點名稱、導覽概述與導航連結，一鍵傳給另一半。

9. **➕ 導覽內容時時維護與更新**
   - 點擊頂部「➕ 新增」，若發現新的真人導覽景點或官方更動時間，直接在網頁上填寫新增或編輯，兩人裝置立即同步！

## 💻 電腦桌面使用方法

1. 開啟本資料夾：`d:\真人導覽地圖`。
2. 雙擊 **`啟動導覽地圖.bat`**。
3. 系統會自動啟動輕量伺服器，並在您的預設瀏覽器中開啟 `http://localhost:8080`。
4. **如何放捷徑在桌面**：
   - 對著 `啟動導覽地圖.bat` 按滑鼠右鍵 ➜ 選擇「傳送到」➜「桌面 (建立捷徑)」。
   - 以後開電腦只要在桌面雙擊此捷徑，就能立刻開啟導覽地圖！

## 📱 兩台 iPhone 手機使用教學 (0 費用永久線上網址)

因為外出旅行時隨時需要用 iPhone 查導覽與 GPS 定位，建議將此專案免費部署至 **GitHub Pages**（100% 永久免費、無限制、安全 HTTPS）：

### 步驟 1：建立免費 GitHub 儲存庫
1. 註冊或登入 [GitHub](https://github.com/)。
2. 點擊右上角「+」➜「New repository」，取名為 `taiwan-tour`（設為 Public）。
3. 將 `d:\真人導覽地圖` 裡面的所有檔案（`index.html`、`manifest.json`、`css`、`js` 等）上傳或推送到該儲存庫。

### 步驟 2：開啟 GitHub Pages
1. 在該儲存庫點擊「Settings」➜ 左側「Pages」。
2. 在「Build and deployment」下的 Branch 選擇 `main`（或 `master`），點擊「Save」。
3. 稍等約 1 分鐘，GitHub 會給您專屬的永久 HTTPS 網址（例如：`https://您的帳號.github.io/taiwan-tour/`）。

### 步驟 3：在兩台 iPhone 加入主畫面 (變成 App)
1. 您與女朋友用 iPhone 的 **Safari 瀏覽器** 開啟上述網址。
2. 點擊螢幕下方正中央的 **「分享」按鈕**（向上箭頭圖示 ⬆️）。
3. 往下滾動找到並點擊 **「加入主畫面 (Add to Home Screen)」**。
4. 點擊右上角「新增」。
5. **大功告成！** iPhone 桌面上就會出現專屬的「真人導覽 🎙️」App 圖示，打開後沒有 Safari 網址列，全螢幕流暢體驗！

## ⚙️ 兩人同步設定 (房間代碼)

1. 打開網頁或 iPhone App，點擊右上角「⚙️」設定按鈕。
2. 在「兩人專屬同步房間代碼」輸入您們兩人的專屬暗號（例如：`ourlove2024` 或 `sweet-tour`）。
3. 點擊「儲存配對」。
4. 女朋友的手機也輸入相同的房間代碼，兩人的收藏與行程即完成連結！
